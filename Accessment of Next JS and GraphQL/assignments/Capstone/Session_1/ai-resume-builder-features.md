# Capstone Session 1: AI-Powered Resume Builder Features

This document outlines 5 unique AI-driven features for an advanced Resume Builder application that go beyond static form-filling inputs.

---

## 5 Unique AI-Powered Features

### **1. Real-Time Applicant Tracking System (ATS) Compatibility Score**
* **Functionality:** As the user types their resume content, an AI engine scans the text against target job descriptions and generates a real-time ATS compatibility score (0-100%), highlighting missing critical technical keywords.

### **2. AI Action Verb & Impact Metric Rewriter**
* **Functionality:** Converts weak, generic bullet points (e.g., *"Worked on React project"*) into high-impact, quantifiable achievements (e.g., *"Engineered responsive React web application, reducing page load time by 40% for 50,000+ monthly active users"*).

### **3. Automated Job Description Match & Resume Tailoring**
* **Functionality:** Users can paste a URL or text of a target job posting, and the AI automatically adjusts resume summaries, skills ordering, and project highlights to align with that specific role.

### **4. AI Interview Question Predictor Based on Resume Content**
* **Functionality:** Analyzes the finished resume and automatically generates a list of 10 likely technical interview questions along with suggested answer frameworks customized to the candidate's listed experience.

### **5. Dynamic One-Click Layout Auto-Formatting & Styling Engine**
* **Functionality:** AI automatically re-balances white space, font sizing, and section margins depending on content density, ensuring the resume perfectly fits onto a clean single page without awkward line overflows.

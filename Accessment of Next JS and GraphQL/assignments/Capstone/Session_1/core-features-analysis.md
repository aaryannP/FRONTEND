## 1. 5 Core Features Inspired by Daily Apps (Zomato, Instagram, Flipkart)

| Feature Name | App Inspiration | User Benefit & One-Sentence Justification |
| :--- | :--- | :--- |
| **1. Real-Time Order Tracking Feed** | Zomato | Keeps users informed of their food status instantly via live Firestore listeners without needing page reloads. |
| **2. Dynamic Category Filter Chips** | Instagram | Enables users to instantly filter food items by category (Pizza, Sushi, Burgers) with visually highlighted active states. |
| **3. Persistent Cart Drawer with Redux Thunk** | Flipkart | Allows users to inspect item totals and apply promotional discount codes smoothly from any page across the app. |
| **4. Auth Session Persistence & Protected Routes** | Instagram | Guarantees user login credentials persist securely across browser reloads using `onAuthStateChanged()`. |
| **5. AI-Powered Personalised Food Recommendations** | Zomato / Swiggy | Delivers curated dish recommendations based on user order history and active dietary preferences. |

## 2. 5 Core Features for a Smart E-Commerce Seller Dashboard (Flipkart Seller Panel)

1. **Real-Time Revenue & Sales Analytics Chart:** Helps sellers instantly track daily gross sales, profit margins, and peak order hours through interactive visual graphs.
2. **Automated Low-Stock Inventory Alerts:** Notifies sellers when product inventory dips below critical thresholds so they can restock before losing potential sales.
3. **AI Dynamic Price Suggestion Engine:** Analyzes competitor market prices and automatically recommends optimal product pricing to maximize sales conversion.
4. **Bulk Order Fulfillment & Shipping Status Tracker:** Allows sellers to process, generate shipping labels, and dispatch multiple customer orders simultaneously in one click.
5. **AI Sentiment Analysis for Customer Reviews:** Summarizes thousands of buyer product reviews into positive and negative sentiment tags so sellers can quickly resolve quality issues.
